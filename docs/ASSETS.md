# Panduan aset

Semua file website berada di `assets/`. Path HTML dan data portofolio dihitung dari `index.html`, bukan lokasi JavaScript.

| Folder | Isi |
| --- | --- |
| `assets/css/` | Style utama dan portofolio |
| `assets/js/` | Menu, data karya, dan galeri |
| `assets/logo/` | `logo-gekrafs.png`: favicon, header, footer |
| `assets/ornaments/` | `panrita-white.svg`: hero dan Tentang |
| `assets/images/hero/` | `hero.jpg` |
| `assets/images/about/` | `kerajinan.jpg` |
| `assets/images/programs/` | `creative-academy.jpg`, `online-marketplace.jpg`, `creative-district.jpg`, `creative-hub.jpg` |
| `assets/images/portfolio/` | Delapan foto aktif; lihat PORTFOLIO.md |
| `assets/images/pengurus/` | Belum tersedia; buat folder saat foto diisi |

Foto pengurus yang diperlukan: `ketua.webp`, `sekretaris.webp`, `bendahara.webp`, `wakil-ketua.webp`, `dewan.webp`, `wakil-sekretaris.webp`, `wakil-bendahara.webp`, `ketua-bidang.webp`. Placeholder tetap bekerja sampai foto tersedia.

Gunakan nama huruf kecil dan ekstensi sesuai format asli. Rasio foto pengurus disarankan 4:5; program 16:9. Usahakan hero di bawah 1 MB dan foto lain di bawah 500 KB bila kualitasnya memadai.

Edit nama pengurus dan WhatsApp di `index.html`; edit karya di `assets/js/portfolio-data.js`. Avatar dan kontak boleh kosong. Inisial dan tombol kontak bersyarat merupakan fitur aktif.
